# **App Name**: Sazwan Digital Canvas

## Core Features:

- Digital Profile Assembler: Dynamically generates a personalized digital business card, pulling data from various sources provided in the prompt.
- AI Profile Summarizer: AI-powered "About Me" generator that summarizes key aspects of Sazwan's professional background. Uses LLM reasoning tool to create different "About Me" versions based on tone and length preferences. This allows Sazwan to pick one fitting the communication context.
- Real-time Update Engine: Allows seamless updating of information, reflecting changes across all instances of the digital card.
- QR Code Generator: Generates QR codes for easy sharing and access to the digital profile, and the URLs of the provided profiles.

## Style Guidelines:

- Primary color: A deep, saturated blue (#3F51B5), representing trust, knowledge, and technological prowess, fitting for a tech innovator's profile.
- Background color: A light, desaturated blue-gray (#ECEFF1), offering a clean and professional backdrop that enhances readability and focus.
- Accent color: A vibrant purple (#7E57C2), analogous to the primary blue, adding a touch of creativity and uniqueness to highlight key interactive elements and calls to action.
- Clean, modern font for main content.
- Clean layout with clear sections for different categories.
- Simple icons to represent the profile links.
- Subtle transitions and loading animations for a polished user experience.
